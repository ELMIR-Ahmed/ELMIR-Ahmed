## 👨‍💻 À propos de moi

Élève ingénieur en dernière année de **Génie Informatique à l'EHEIM**, je conçois et développe des applications web complètes, de l'architecture de l'API jusqu'à l'interface, puis je les conteneurise et les déploie.

- 🚀 **Full stack** : React / TypeScript côté front ; Symfony (API Platform), Spring Boot et ASP.NET Core côté back
- 🧩 **Architecture** : conception d'API REST, MVC, microservices
- ⚙️ **DevOps & Cloud** : Docker, CI/CD (GitLab CI, Jenkins), Ansible, supervision avec Grafana / Prometheus, services AWS
- 🏫 **En ce moment** : développement d'un **ERP scolaire modulaire** pour le Groupe Scolaire Rihab Al Marjane
- 🎨 **UI/UX** : maquettes et refonte d'interfaces sur Figma
- 🤝 **Méthode** : travail en équipe, Scrum, suivi des tickets sur Jira
- 🤖 **Hors code** : Machine Learning et musique
